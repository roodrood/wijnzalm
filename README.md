# Wijnzalm — Wine Forum Knowledge Lake

Onafhankelijk onderzoeksproject om forumkennis van **Vinejo** en **La Passion du Vin** vindbaar te maken.

## Werkvolgorde
1. Test DNS, HTTP en `robots.txt` vanaf GitHub Actions (geen bulkcrawl).
2. Bevestig de toegestane crawl- en archiveringsscope per forum.
3. Indexeer categorieën, topics en berichten in een hervatbare pipeline; valideer dekkingscijfers.
4. Structureer wijnkennis met bronnen, onzekerheden en meningsverschillen.
5. Pas de kennislake pas daarna toe op wijnshops.

**Status:** de live volledige forumcrawl is nog niet uitgevoerd. Bewaar geen volledige forumteksten zonder de vereiste toestemming. De toegangsproef is uitsluitend diagnostisch.
